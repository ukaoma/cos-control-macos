5. What every handoff now asks the agent

Added to every handoff when it is sent, so it can’t be edited out of a draft. The line goes at the top of the final reply because the server keeps a reply’s first 4,000 characters. A line naming a task this session was never given is ignored.

When you finish this task, or if you need input or are blocked, start your reply with this line so COS can track it: COS-WORK 3f9a2c1b7d4e: <done, needs input or blocked>: <one sentence of evidence> Use done only when the Done when line above is met. If you are handling several COS tasks, give one line per task.

Pick

  • 3A (shown): the why-line on the card, plus the latest-move strip above the columns.
  • 3B: the why-line on the card only, with no strip. This is quieter. A jump is explained only on the card itself.
  • Notifications: received, done and needs input (shown). Or just done and needs input.
  • “Not done yet” in the status box: it moves the card back and tells the session what is missing. Or leave that out for now.
