01Hold the shortcut: the pet listens

While you hold the shortcut, the ledger under the pet becomes a listening pill with a live waveform. It replaces the RUNNING / DONE row only while you speak, then hands it back.

  • Bars respond to quiet speech: level on a decibel scale (-50 to -10 dBFS), fast rise, slow fall.
  • No window opens. Nothing takes focus from the app you are typing in.
  • The timer shows how long you have held it. The cap stays two minutes.

02Pet hidden: a small pill above the Dock

If the pet is off, COS shows the same waveform as a dark floating pill at the bottom center of the screen, the way Wispr does. It disappears when the text lands.

  • Same pill in both places, so the meaning never changes.
  • It never takes clicks while you speak, so it cannot steal focus.

03Release: text drops in where your cursor is

COS transcribes with Parakeet and your dictionary, copies the text to the clipboard, and pastes it into whatever text box has the cursor when it finishes. You can click somewhere else while it transcribes; it follows the cursor, like Wispr.

  • The pill reads TRANSCRIBING, then flashes INSERTED with the app name for about 1.5 seconds.
  • The text stays on the clipboard, so ⌘V works again anywhere.
  • Still refused: password fields and secure input. COS never presses Send or Return.

04No text box selected: a short-lived card on the pet

When the cursor is not in a text box (Finder, the desktop, a canvas), the text is already copied, and a card pops over the pet with the transcript and a big Copy button.

  • The ring on × counts down 20 seconds, then the card folds away. Hovering pauses it.
  • Nothing is lost: it stays in Recent dictations.
  • With the pet hidden, the same card rises from the bottom pill instead.

05A Dictated pill and Recent dictations on the pet

A fourth pill joins the ledger. Clicking it opens Recent dictations in the same list the pet uses for sessions: newest first, where each one went, and a Copy on every row.

  • Each row: time, words, and where it landed (inserted into an app, or copied with no text box).
  • Click a row to see the full text and Fix a word.
  • The pill only shows once you have dictated something.

06Fix a word: the dictionary learns

Tap the wrong word, type the right one, Save. It goes into the one COS dictionary, the same one your G2 meetings, Mac recordings and dictation already use, so the fix follows you everywhere from the next sentence on.

  • The right spelling joins the vocabulary, and "heard → written" joins the corrections.
  • Recent corrections show what was learned, from which surface, and when. Each one can be undone.
  • Stored in your COS profile on this Mac, so it survives restarts and updates.

07Dictionary in COS Activity

A Dictionary tab shows everything COS has learned: recent corrections first, then vocabulary and all corrections, each editable and searchable. This is the first screen for a dictionary that already exists on the server but had no home in COS Control.

  • Add a word or a correction by hand, or undo one the pet learned.
