Work: files on a card

Route A for 0.5.254, with your picks applied. Drop files on a card, and the card keeps copies in ~/cos-data/work-context. When you send, the copies' paths go out with the handoff, on every platform. A dropped folder stays a link marked "may change". Copies are cleaned up 14 days after the card is complete.

Three places change: the board, the Agent workspace and the Start sheet. Everything else on Work stays as it is. This is a mock: the names, sizes and states are examples.

1. The board: drop a file on a card

The whole card is the drop target. While a file is over it, the card shows Add to card. A card only accepts files, and columns and the session row only accept cards. A file dropped on the session row does nothing and says where to put it. A drop never sends anything.

4. What the card says when it won't take a file

Every refusal names the reason on the card. Nothing fails silently, and nothing is half-added.

DropThe card says
.env, *.pem, id_rsa, a keychain, .cos-profile.jsonNot added: .env looks like a secrets file. Files like this never go to a provider.
The 21st file, or past 2 GB on the cardNot added: a card holds 20 files and 2 GB. Remove one to add this.
An app, a disk image, an installerNot added: an agent can't read an app or a disk image.
A file already on the card (same contents)Already on this card as "Korona vs Bottle POS pricing.pdf".
An iCloud file that won't downloadNot added: iCloud didn't download "Q3 deck.pdf" within a minute. Try again once it's downloaded.
A link dragged from a browserAdded as a link, not downloaded. The agent opens it itself.
