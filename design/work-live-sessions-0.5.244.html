4. What you added: layout switch, drag to start, confirm before it runs

Board / Focus sits in the Work header and remembers your choice. Board is the dashboard (1A): sessions working across your domains on top, the Kanban below. Focus is the list with the Agent workspace pinned right (2A). The counts open the matching list in Focus. Drag a card between columns to change its stage, or onto Start work in the sessions row to put a session on it. Nothing runs on drop: an overlay confirms first. If Jev or a saved draft already says where it goes, the overlay is one line and one button. If not, it asks where: continue, fork or new, which session, and the context.
